A program that draws one image summing up 25 November 2026 world news, built for make.fun's "Sum up 25 November's world news in one image" bounty ($100 in USDC). Six stories from 25 November 2026 — Shenzhou-24 launches with the first foreign astronaut on Tiangong, the US proposes tariffs on 14 trading partners, an Israeli strike kills a Hamas official in Gaza, Bangladesh raises the garment minimum wage 36 percent, all hostages are freed in Cartagena, and rescuers search a flooded gold mine in Indonesia — drawn as a flat 1024x1024 poster with a pixel font, no libraries, no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes `entry.png` (1024x1024) to the output directory (`/output` by default). Python 3.13, standard library only. Deterministic: running it twice writes identical bytes.
